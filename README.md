# SwingDesk — документация

Формализованная, версионируемая, проверяемая и объяснимая предметная модель
свинг-трейдинга и техническая спецификация будущей платформы. Строится по
мастер-ТЗ v1.0 (2026-08-04). Основной язык — русский; идентификаторы — английский.

> **Фаза:** документация, минимум кода. Уроки в разработке (неполны) — доменное
> наполнение ждёт их; source-independent каркас строится вперёд.

## Шесть сквозных требований (в `01`)

Выведены из post-mortem предыдущей системы (TradAlert) и вшиты с самого начала —
чтобы конкретные режимы отказа были невыразимы, а не отлавливались аудитом позже:

- `REQ-VALIDATION-001` — нет константного гейта (mutation-проверяемость)
- `REQ-VALIDATION-002` — тождество backtest/live
- `REQ-DATA-001` — календарь point-in-time, ноль литералов дат
- `REQ-OUTPUT-001` — провенанс у каждого числа в выводе
- `REQ-EVIDENCE-001` — validation stage требует реально исполнившегося прогона
- `REQ-RISK-001` — нет «тёмного» выключателя риск-контроля
